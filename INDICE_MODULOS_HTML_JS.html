Nota de compatibilidad: el HTML y el JavaScript funcionales permanecen en sus archivos originales. Separarlos físicamente en fragmentos o módulos ejecutables requeriría cambiar cómo se cargan las vistas y cómo se comparten funciones y estado; por eso este índice organiza la estructura sin alterar la ejecución ni el acceso local actual.
